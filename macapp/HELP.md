# BITT — วิธีใช้

BITT อยู่บน **menu bar** (ไอคอนหกเหลี่ยมมีลูกศรลง ด้านขวาบนของจอ)
คลิกที่ไอคอนเพื่อเปิดแผงควบคุม — เพิ่ม torrent, ดูความคืบหน้า, หยุด/เล่นต่อ, เปิดโฟลเดอร์ดาวน์โหลด

ถ้ากำลังโหลดอยู่ ไอคอนจะแสดงความเร็วดาวน์โหลดข้าง ๆ ด้วย

## เพิ่ม torrent

- คลิกไอคอน menu bar → **Add Torrent File…**
- คัดลอก magnet link แล้วคลิกไอคอน → **Add Magnet from Clipboard**
- คลิก magnet link ในเบราว์เซอร์ได้เลย
- ดับเบิลคลิกไฟล์ `.torrent` ใน Finder (ครั้งแรกคลิกขวา → Open With → BITT)
- ลากไฟล์ `.torrent` มาวางบนหน้าต่างหลัก

ไม่ว่าจะเพิ่มทางไหน **BITT จะเด้งขึ้นมาถามก่อน** หน้าต่างจะบอกชื่อ ขนาด จำนวนไฟล์
และโฟลเดอร์ปลายทาง พร้อมสามปุ่ม:

- **Download Now** — เริ่มโหลดเลย
- **Add Paused** (⌘P) — ใส่ในรายการแต่ยังไม่โหลด ค่อยกดเล่นทีหลัง
- **Cancel** — ไม่เพิ่ม

เปลี่ยนโฟลเดอร์เฉพาะ torrent นั้นได้จากปุ่ม **Change…** ในหน้าต่างเดียวกัน
ถ้า torrent นั้นมีอยู่ในรายการแล้ว แอปจะบอกแทนที่จะเพิ่มซ้ำ

ปิดการถามได้ที่ **Settings → Downloads → Ask before adding a torrent**

## หน้าตา

บน macOS 26 ขึ้นไป พื้นผิวที่ลอยอยู่ (หน้าต่างถามตอนเพิ่ม torrent, แผงจาก menu bar,
แถบโฟลเดอร์ด้านล่าง, ปุ่มในหน้าจอว่าง) ใช้ **Liquid Glass** ของระบบ
บนเวอร์ชันเก่ากว่านั้นจะกลับไปใช้วัสดุแบบเดิมให้อัตโนมัติ

## Ratio กับการแชร์กลับ

แถวของ torrent ที่เคยอัปโหลดจะมี **shared** (ยอดสะสม) กับ **ratio** ต่อท้าย
ตัวเลขนี้นับข้ามการเปิดปิดแอป ไม่รีเซ็ตเหมือนความเร็วชั่วขณะ

มุมซ้ายล่างมีจุดบอกว่า **คนอื่นต่อเข้ามาหาเราได้หรือยัง**

- 🟢 เขียว = มี peer ต่อเข้ามาแล้ว อัปโหลดได้เต็มที่
- 🟠 ส้ม = ยังไม่มีใครต่อเข้ามา โหลดได้แต่แชร์กลับได้น้อย ratio จะขึ้นช้า

แอปจะลองขอให้เราเตอร์เปิดพอร์ตให้อัตโนมัติ (NAT-PMP แล้วต่อด้วย UPnP)
เอาเมาส์ชี้ที่จุดนั้นเพื่อดูว่าเราเตอร์ตอบว่าอะไร ถ้าเราเตอร์ไม่รองรับ
ต้องตั้ง port forwarding เองที่หน้าเว็บเราเตอร์ (TCP พอร์ต 6881 มาที่เครื่องนี้)

## จำกัดความเร็ว

**Settings (⌘,) → Speed** ตั้งเพดานดาวน์โหลดและอัปโหลดเป็น MB/s ใส่ 0 = ไม่จำกัด
ใช้ร่วมกันทุก torrent เหมาะกับการ seed ทิ้งไว้โดยไม่กินเน็ตบ้าน
เมื่อจำกัดอยู่ จะมีไอคอนมาตรวัดขึ้นข้างความเร็วรวมที่แถบซ้าย

## magnet link ใช้ได้แค่ไหน

BITT อ่าน info-hash จากลิงก์ → ถาม tracker ที่อยู่ในลิงก์ → ได้ peer →
แล้วดึงรายละเอียด torrent (รายชื่อไฟล์ ขนาด) มาจาก peer โดยตรง

**ใช้ได้กับ magnet ที่มี tracker ติดมาด้วย** (มี `&tr=` ในลิงก์) ซึ่งก็คือเกือบทุกลิงก์
ที่ก๊อปมาจากเว็บ

**ใช้ไม่ได้กับ magnet เปล่า ๆ** ที่มีแต่ `xt=urn:btih:...` เพราะ BITT ไม่มี DHT
ซึ่งเป็นการตัดสินใจ ไม่ใช่ของที่ลืมทำ — torrent จาก private tracker ห้ามใช้ DHT อยู่แล้ว
และ DHT ทำให้แอปต้องรับข้อมูลจากเครือข่ายสาธารณะตลอดเวลา

เจอลิงก์แบบนี้ แอปจะเตือนตั้งแต่ตอนกดเพิ่ม จะได้ไม่ต้องมานั่งงงว่าทำไมไม่ขยับ

## สีบอกสถานะ

| สี | สถานะ |
|---|---|
| 🔵 น้ำเงิน | กำลังดาวน์โหลด |
| 🟢 เขียว | กำลังแจกจ่าย (seeding) |
| 🟠 ส้ม | หยุดชั่วคราว |
| 🟦 เขียวอมฟ้า | เสร็จแล้ว ไม่ได้แจกจ่ายต่อ |
| 🟣 ม่วง | กำลังหา metadata |

สีเดียวกันนี้ใช้ทั้งไอคอนสถานะ แถบความคืบหน้า ตัวเลขเปอร์เซ็นต์ ไอคอนในแถบซ้าย
และความเร็วขึ้น–ลง (ลง = น้ำเงิน, ขึ้น = เขียว)

## หน้าต่างหลัก

เปิดจากแผง menu bar → *Open Main Window* หรือกด ⌘1

**แถบโฟลเดอร์ดาวน์โหลดอยู่ล่างสุดของหน้าต่าง** บอกว่าตอนนี้เซฟลงที่ไหน พร้อม:

- ปุ่ม **Change…** เปลี่ยนโฟลเดอร์
- ปุ่มลูกศร เปิดโฟลเดอร์นั้นใน Finder
- ช่อง **Ask each time** — ติ๊กไว้แล้วมันจะถามโฟลเดอร์ทุกครั้งที่เพิ่ม torrent ใหม่
  ใช้ได้กับทุกทางที่เพิ่ม รวมถึงตอนคลิก magnet link จากเบราว์เซอร์

เปลี่ยนจากที่อื่นก็ได้: เมนู **Transfers → Change Download Folder…** หรือ **Settings (⌘,)**

แถบรายละเอียด (Files / Peers / Trackers / Log) **ซ่อนไว้เป็นค่าเริ่มต้น**
เรียกขึ้นมาด้วย **⌘I** หรือปุ่มขวาสุดของ toolbar

toolbar เหลือ 4 ปุ่มเท่านั้น:

- **+** เพิ่ม torrent (กดค้างเพื่อเลือกระหว่างไฟล์ `.torrent` กับ magnet link)
- **▶ / ⏸** หยุดหรือเล่นต่อรายการที่เลือก
- **🗑** ลบรายการที่เลือก
- **▣** เปิด/ปิดแถบรายละเอียด

ที่เหลือย้ายไปอยู่ในคลิกขวา (Show in Finder, Copy Magnet Link) และดับเบิลคลิกที่แถว
เพื่อเปิดใน Finder — ใช้ลูกศรขึ้น/ลงเลื่อนรายการได้

## ปุ่มลัด

| คีย์ | ทำอะไร |
|---|---|
| ⌘O | เปิดไฟล์ `.torrent` |
| ⇧⌘V | เพิ่ม magnet link จากคลิปบอร์ด |
| ⌘I | เปิด/ปิดแถบรายละเอียดด้านล่าง |
| ⌘1 | เปิดหน้าต่างหลัก |
| ⌘. | หยุดทั้งหมดชั่วคราว |
| ⇧⌘. | เล่นต่อทั้งหมด |
| ⇧⌘D | เปิดโฟลเดอร์ดาวน์โหลด |
| ⌘, | ตั้งค่า |
| ⌘Q | ออกจากโปรแกรม |

## สิ่งที่ควรรู้

- ปกติ BITT **ไม่ขึ้นใน Dock** — อยู่บน menu bar อย่างเดียว
  อยากให้ขึ้นใน Dock ด้วยให้เปิด *Show BITT in the Dock* ใน Settings
- ปิดหน้าต่างไม่ใช่การออกจากโปรแกรม มันจะ seed ต่อให้ — สั่งออกจริงด้วย ⌘Q
- หยุดกลางคันได้ เปิดใหม่แล้วมันจะตรวจไฟล์เดิมแล้วโหลดต่อจากจุดที่ค้าง
- ยังไม่มี DHT — magnet link ที่ไม่มี tracker ติดมาจะหา peer ไม่เจอ
- ครั้งแรกที่เปิด macOS อาจถามเรื่องอนุญาตการเชื่อมต่อขาเข้า ให้กด Allow
